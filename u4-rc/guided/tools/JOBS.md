# Image jobs - guided LP/HP activity (electronics, grade 11)

Generate each image below with the imagegen skill's built-in image_gen tool (not the CLI fallback, not
scripts/image_gen.py, not OPENAI_API_KEY). One image per job. Save each one as a PNG in the folder `out`
next to this file, using exactly the file name given (copy it there from wherever the tool saves it).
Skip a job whose PNG already exists in `out`. When all are saved, print the list of saved files and stop.

## Style (append to every job)
Style: vintage technical illustration in the manner of a 1950s electronics handbook, confident navy-blue ink
line work with fine cross-hatching, soft watercolor washes in teal, amber and coral, on clean off-white paper.
No text, no letters, no numbers, no labels, no writing of any kind, no people, no faces, no logos.
